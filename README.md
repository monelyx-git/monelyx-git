## 🚗 Gig — every mile counts

You drove 1,100 miles this month. How many did you log?

Gig counts them for you. Start a shift with one tap and it keeps logging with the screen off, even when you lose signal, while your deduction grows in real time.

| | |
|---|---|
| **Never lose a mile** | No signal, screen off, app closed by iOS: your miles stay saved. |
| **Glanceable** | Live Activity, widgets, Siri and the Action button. |
| **Receipts by photo** | Snap it, and it stays attached to the expense. |
| **Review and edit** | Split, merge or mark any trip as personal. |
| **Your data is yours** | Location is used only while a shift is active. Delete your account, delete your data. |

Works with any delivery or rideshare app.

## 🧭 How we build

- **Do one thing well.** Every product starts from a single, concrete pain.
- **Respect the user's data.** Collect the minimum, explain it plainly, delete it on request.
- **Ship it in two languages.** English and Spanish from day one.
